# A股横截面多因子研究

本项目研究A股横截面多因子的预测能力，并在避免前视偏差和幸存者偏差的前提下，构建包含交易成本与可交易性约束的组合。

当前处于研究协议与60日动量小闭环（MVP）建设阶段。现阶段结果仅用于验证数据、因子评价和回测管道，不构成最终投资结论。

## 研究边界

- 原始数据位于 `Data/`，只读且不进入Git。
- 研究、验证、最终测试和小闭环区间统一定义在 `configs/research_protocol.yaml`。
- 最终测试期在研究协议、因子选择和组合规则冻结前保持封存。
- 可复现逻辑放在 `src/ashare_multifactor/`，Notebook不作为唯一实现。
