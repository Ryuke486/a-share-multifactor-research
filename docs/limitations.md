# v1.0 已知限制

## 结论边界

1. **没有最终样本外结论。** 2022–2025 最终测试期继续封存；v1.0 不报告该区间策略收益，也未通过检查点 C。
2. **验证期组合收益为负。** 三个候选在 2017–2021 的净年化收益均为负。滚动 IC 方案只是按冻结的相对规则胜出，不代表验证期盈利。
3. **研究期收益不能外推。** 2005–2016 完整成本回测年化收益为 17.6031%，但最大回撤为 -66.9638%；研究期结果同时参与了研究设计形成，不能作为最终样本外证据。

## 数据限制

1. 原始行情来源、授权和再分发权仍需补全说明；因此原始 CSV 不进入 Git。
2. PE、PB、PS 的历史 point-in-time 口径未获得完整证据，价值因子最多为 watch。
3. 历史行业分类与 ST 字段口径未完全核验；本版本不据此给出严格行业中性化结论。
4. 2026 年 5 月原始数据不完整，但该区间不属于 v1.0 研究或验证样本。
5. 免费公开公司行动和证券事件数据存在语义与可得性限制；项目用官方公告、不可变缓存和审计清单降低风险，但不能证明数据源绝对无遗漏。

## 模型与执行限制

1. 回测使用日线和开盘成交近似，不能模拟盘口排队、逐笔冲击或真实券商成交质量。
2. 佣金、滑点、冲击和容量均为冻结模型假设。稳健性结果表明成本口径可使年化收益产生数个百分点差异。
3. 订单最终成交率约为 49.43%，平均目标 L1 偏离约为 32.34%；目标组合与实际持仓存在显著差距。
4. 最长陈旧估值达到 373 天，虽已绑定停牌证据并单独审计，仍会降低极端停牌期 NAV 的经济可解释性。
5. 未使用复杂机器学习模型；这是为降低过拟合并保持可解释性，不意味着简单模型天然更优。

## 稳健性限制

1. 稳健性分析覆盖研究期与验证期，不是独立的第二个最终测试集。
2. `portfolio_universe_high` 因超过冻结上游股票池而未运行。
3. `regime_pre_registered` 因历史行业 point-in-time 未核验而只能描述性报告。
4. 稳健性实验不用于按收益重新选择主方案；否则会把验证样本变成新的训练样本。

## 交付与授权限制

1. Git 仓库不包含 `Data/`、`processed/`、`artifacts/`、官方公告缓存或其他大文件；完整结果复验需要本地数据和 machine-readable release。
2. v1.0 是文档型 release，没有新增 `processed/project_delivery/CURRENT.json` 或 delivery Python 流水线。
3. 仓库中由 `Ryuke486` 原创的源代码和原创文档采用 MIT License；`Data/`、`processed/`、`artifacts/`、官方公告、原始市场数据及其他第三方材料不属于该授权范围。
4. Stage 9 的失败 attempt、HANDOFF 和事故证据仍是审计历史，但已从 v1.0 完成条件中移除；它们不能被表述为 Stage 9 通过。
