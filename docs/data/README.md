# 数据目录、覆盖与限制

本页记录当前本地原始数据的已核验事实和第一版使用边界，不发布任何原始CSV。`Data/` 是只读输入；不得修改、改名、移动、删除或提交其中的文件。

## 目录布局

```text
Data/
├── 每天一个文件/
│   ├── 不复权/
│   ├── 前复权/
│   └── 后复权/
└── 每只股票一个文件/
    ├── 不复权/
    ├── 前复权/
    └── 后复权/
```

当前数据约28GB、36,669个CSV。按已核验清单，每种复权口径各有6,382个交易日文件和5,841个证券文件。

第一版数据底座只使用：

```text
Data/每天一个文件/不复权/
Data/每天一个文件/后复权/
```

两边必须按 `(date, symbol)` 严格一对一连接。每日不复权数据用于研究字段和成交状态，后复权价格用于总收益与跨期收益；前复权数据和“每只股票一个文件”不是第一版输入。
构建后的 `processed/daily_panel/manifest.json` 记录每个年度分区的相对路径、行数、日期范围、文件大小和SHA-256；分区缺失、多出或内容被替换时，后续阶段会拒绝运行。

## 已核验覆盖与Schema

- 日文件日期覆盖2000-01-04至2026-05-14，共6,382个交易日文件。
- 每股票文件覆盖5,841个证券代码。
- 6,378个日文件为38列；最后4个日文件为37列，缺少“是否融资融券”字段。读取器会显式补为空值，不静默改变其他字段。
- 2026年5月数据不完整，交易日序列存在缺口；该月份不能直接当作完整研究区间。
- 证券代码必须保留为六位字符串，禁止转为整数。

## 来源、授权与字段口径

以下信息仍需用户补全或进一步核验：

- 数据提供方、下载时间、授权范围，以及能否在研究展示或GitHub仓库中发布派生样例。
- 历史行业字段是否为当时可得口径。
- PE、PB、PS等估值字段是否严格point-in-time。
- 2026年5月缺口的原因及完整性状态。

在口径核实前，所属行业、估值和两融字段必须在研究报告中披露限制。数据内预计算的涨幅和均线不作为最终因子来源；退市时间可能包含未来信息，不得用于历史股票池过滤。后复权价格与原始市值不在同一价格尺度，禁止用后复权价格乘股本重算市值。

## Git与发布边界

- 原始 `Data/`、生成的 `processed/` 和 `artifacts/` 均不提交Git。
- GitHub只允许提交人工合成的小型测试夹具、极小样例、字段字典、数据清单、哈希和构建脚本，不提交任何原始CSV。
- 任何全量扫描约28GB数据的操作，必须先用人工夹具或小日期范围验证，并提前评估资源消耗。

由于当前macOS文件系统大小写不敏感，仓库不能同时安全使用 `Data/` 和独立的 `data/` 文档目录，因此本说明存放在 `docs/data/`，避免写入只读原始数据目录。
