# 公司行动数据证据

**核验日期：** 2026-07-14  
**研究边界：** 只保留2005-01-01至2016-12-31生效的公司行动。

## 免费数据路线

1. 东方财富分红配送，通过AKShare 1.18.64的`stock_fhps_em`获取，作为全市场主源。
2. 新浪分红与配股历史，通过`stock_history_dividend_detail`获取，对复权跳变未解释证券补源。
3. 巨潮历史分红和公司股本变动，通过`stock_dividend_cninfo`与`stock_share_change_cninfo`获取，用于交叉核验及识别股权分置、缩股和重组。
4. 上交所历史分红/送股页面和沪深交易所/巨潮实施公告，作为抽样及异常事件的权威证据。

数据来源入口：

- https://akshare.akfamily.xyz/data/stock/stock.html
- https://www.sse.com.cn/market/stockdata/dividends/dividend/index_his.shtml
- https://www.sse.com.cn/market/stockdata/dividends/bonus/
- http://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search

## 覆盖率核验

以后复权收盘/原始收盘的比例变化只作为异常发现工具，不直接生成公司行动。审计把原始价视为四舍五入后的±0.005元区间；只有相邻复权因子可行区间不重叠时才判为异常。公司行动在停牌期间生效时，对齐到生效日后首个有效观测。

- 原0.5%阈值审计有250次、62只证券待核验；价格区间法将其收窄为98次、52只证券。
- 巨潮官方实施公告补齐21个非标准股改/对价事件，其中`600225`流通股东每10股获0.9281361股。
- 余77次涉及33只证券；76次总股本未变化，且集中在少数数据日期，归类为复权影子序列异常。
- 唯一总股本跳变为`000981`在2011-08-26恢复上市。巨潮公告59839449证明新增698,005,200股是向控股股东定向发行购买资产，并非普通持仓按5.335倍增股；普通流通股东的股改对价已于2011-05-30另行到账。
- 标准化后，阶段五目标证券共有15,923条现金分红/送转及特殊事件进入正式账本；配股流水保留审计但基准账户不主动认购。
- 巨潮税前派息记录在2005–2016年含12,004条，1,691只证券，派息日缺失0条；唯一原始结构化缺失`002090`由巨潮官方实施PDF 21365490补证。
- 账本在除权日确认应收股利，仅在派息日转入可用现金；持仓加权影子最大单日偏差为0.3693%，低于冻结0.5%门槛。

## 当前结论

免费公开数据路线已达到正式账本门禁，状态为`ready`。账本使用东财/新浪送转事件、巨潮税前派息日及官方实施公告，不把影子复权跳变静默转换为现金或股数。个人股息红利差别税不在本阶段建模；配股默认不参与。
